1. Главный экран

Задача: за 5 секунд объяснить, кто ты и зачем клиенту ты нужен.

Сильный заголовок про результат для бизнеса.
Короткое пояснение.
Сайты · Веб-сервисы · Автоматизация · Telegram-боты
Обсудить проект →
Главный визуал: код → готовый веб-интерфейс.
2. Процесс

Задача: снять страх «программист исчезнет / не доведёт».

Идея → Проектирование → Разработка → Запуск

Показывать не технические этапы, а что получает клиент на каждом шаге.

3. Избранные проекты

Задача: доказать компетентность.

3–5 сильных работ.

Каждая карточка:

что было;
что сделал;
конкретный результат;
ссылка на проект.

Здесь можно использовать бенто только для избранных карточек.

4. Результаты

Задача: показать ценность через цифры.

Например:

+X% заявок;
X часов сэкономлено;
X дней до запуска;
X пользователей.

Только реальные подтверждённые показатели.

5. Что могу сделать

Не каталог технологий, а задачи бизнеса:

запустить новый сайт;
автоматизировать ручную работу;
создать внутренний сервис;
разработать Telegram-бота;
превратить идею в работающий продукт.
6. Почему со мной

Коротко, без стандартных «ответственный / коммуникабельный / стрессоустойчивый».

Например:

один исполнитель от идеи до запуска;
быстрое создание первой рабочей версии;
самостоятельное решение технических вопросов;
доведение проекта до результата.
7. Финальный призыв

Большой спокойный экран:

Есть идея продукта? Давайте обсудим её.

Обсудить проект →

Итоговая структура:
